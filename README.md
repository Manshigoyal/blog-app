# Blog App

A Full Stack Blog Application built using Node.js, Express.js, MongoDB and EJS.

## Features

- User Authentication
- Add Blog
- Edit Blog
- Delete Blog
- Like System
- Comment System
- Search Blogs
- Categories
- Dark Mode
- Responsive Design
- User Author Name

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap

## Installation

```bash
npm install
node server.js
```
